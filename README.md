# Basic Express Testing

A basic express setup for testing purposes

Includes

- Express
- Webpack
- Prettier
- ESLint
- TypeScript
- SCSS Modules

## Setup

- `npm i`
- Run the server
- Build frontend assets
- Visit http://localhost:8080

## All Helpful Commands

Run the server:

```
$ npm run server
```

Run the frontend:
```
npm run webpack:watch
```

Fix issues:

```
$ npm eslint:fix
```
